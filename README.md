# Хроника Монет (Chronicles of Coins)

Учёт личных финансов в виде игры. Ведёшь доходы и расходы, копишь на цели и гасишь долги, а твой герой с компаньоном проходит путь вместе с тобой.

**Открыть приложение:** https://dqsha.github.io/Chronicles-of-coins/

Текущая версия: см. `version.json`.

## Возможности

- **Счета.** Несколько счетов и общий баланс («Всего на счетах»).
- **Доходы и расходы.** Запись трат и поступлений по категориям, своя история трат.
- **Банковские выписки.** Загрузка файла выписки вместо ручного ввода.
- **Аналитика.** «Куда уходят деньги», сколько обычно тратишь в день и сколько можно тратить.
- **Цели накоплений.** Ближайшая цель и прогресс по ней.
- **Долги и рассрочки.** Обязательные платежи с напоминанием о дне оплаты.
- **Игровой слой.** Герой и компаньон, достижения, серия «дней без трат», звук.
- **Копия данных.** Сохранение в файл и восстановление из копии.

Данные хранятся только в браузере на твоём устройстве (`localStorage`). На сервер ничего не отправляется, поэтому время от времени делай копию данных.

## Структура проекта

| Путь | Что там |
|---|---|
| `src/index.html` | Исходник приложения: одна страница, логика между `// ==LOGIC==` и `// ==END LOGIC==` |
| `index.html` | Собранная версия для сайта. **Не править вручную**, собирается скриптом |
| `version.json` | Текущая версия, по ней приложение предлагает «Обновить» |
| `test/` | Тесты (`check.js`, `ui.js`, `v05`–`v13`) |
| `tools/` | `release.sh` (выкладка), `build.py` (сборка), `assets.py` (обработка картинок) |
| `assets/` | Картинки, иконки и шрифты |
| `prompts/` | Промпты для генерации картинок в Gemini |
| `docs/WORKFLOW.md` | Подробная инструкция для разработки |

## Разработка

Требуется Node.js (для тестов) и Python 3 (для сборки).

1. Правки вносятся только в `src/index.html`.
2. Перед выкладкой подними `APP_V` в `src/index.html`, иначе пользователи не увидят «Обновить».
3. Проверить тест вручную:
   ```bash
   node test/check.js src/index.html
   ```
4. Выложить:
   ```bash
   bash tools/release.sh "что изменилось"
   ```
   Скрипт прогоняет все тесты, собирает `index.html`, пишет `version.json` и делает push. Если хоть один тест красный, выкладка останавливается.

## Картинки

Новые картинки генерируются по промптам из `prompts/` и кладутся в `assets/`. Фон `#FF00FF` вырезается скриптом `tools/assets.py`.
