# Как работать с проектом (для нового чата)

- Исходник приложения: `src/index.html` (одна страница, логика между `// ==LOGIC==` и `// ==END LOGIC==`).
- Правки вносить только в `src/index.html`. Корневой `index.html` собирается автоматически, руками не править.
- Тесты: `test/*.js`, запуск каждого: `node test/check.js src/index.html`.
- Выкладка: `bash tools/release.sh "сообщение"`. Скрипт гоняет все тесты, собирает `index.html`, пишет `version.json` из `APP_V` и делает push. Красный тест останавливает выкладку.
- Перед выкладкой поднять `APP_V` в `src/index.html` (иначе приложение не предложит «Обновить»).
- Картинки: `assets/`; обработка (вырезание фона #FF00FF) в `tools/assets.py`.
- Промпты для Gemini: `prompts/`.
- Блокнот проекта (журнал версий, решения, идеи): https://claude.ai/artifact/MKvPn13HyA8WfVsq2r2yP1. Дописывать после каждой версии.
